# Layout-pass — store fotos (Peter 2026-09-04)

**“Som TradingView”** = store billeder der *fylder*, ikke trading-UI.

## Regler
- Væk: pladsholder-kasse, branche-chips/pills.
- Hver blok har et **stort Pia-foto**.
- Hero: **full-bleed** foto; H1 + CTA som overlay (navy 30–45 %).
- Næste blok: **to store døre** (hvert sit foto) — Find vikar / Find job.
- Brancher: **billedgitter** (foto pr. eksempel), ikke chips. Copy: eksempler, ikke dækning.
- Farver beholder: Sol `#FFE14A`, Signal `#FF4D8D` — på **knapper** og overlay, ikke som erstatning for foto.
- Ingen GitHub.
- Screens 375+1280 **først når foto er i**, ikke før.
